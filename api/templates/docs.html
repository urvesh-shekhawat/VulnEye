VulnEye Developer & CI/CD API

Seamlessly trigger security scans and automate penetration tests directly from your terminal, deployment scripts, or CI/CD pipelines.

Authentication

Pass your personal API key via HTTP Bearer token in the Authorization header:

Authorization: Bearer vye_live_your_api_key_here
GET /api/v1/health

Check sentinel daemon uptime and API operational status.

curl -X GET "http://127.0.0.1:5000/api/v1/health"
POST /api/v1/scan

Execute high-speed multi-threaded vulnerability scan on a target URL.

curl -X POST "http://127.0.0.1:5000/api/v1/scan" \ -H "Authorization: Bearer vye_live_your_key" \ -H "Content-Type: application/json" \ -d '{"url": "https://scanme.nmap.org"}'
GET /api/v1/history

Fetch past security audit logs for the authenticated organization.

curl -X GET "http://127.0.0.1:5000/api/v1/history" \ -H "Authorization: Bearer vye_live_your_key"
