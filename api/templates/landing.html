Frequently Asked Questions

Is scanning safe and non-destructive for my production server? ▼
Yes! VulnEye uses strictly non-destructive external reconnaissance. We probe public HTTP response headers, SSL/TLS certificates, open network ports, and DNS metadata. We do not inject malicious database exploits or initiate denial-of-service traffic.
How does the Bilingual AI Remediation Engine work? ▼
Our AI Explainer translates complex CVE and OWASP vulnerabilities into conversational English or Hindi (हिंग्लिश). It provides an executive risk summary, explains what attackers can achieve, and generates copy-paste configuration code for Nginx, Apache, or Node.js.
Can I automate scans using Webhooks and CI/CD? ▼
Yes! You can generate secure API keys from Account Settings and configure Discord, Slack, or enterprise SIEM webhooks to receive real-time notifications whenever a high-severity vulnerability is detected.
How do I generate and download Executive PDF Dossiers? ▼
Every completed scan comes with an auto-generated, board-ready executive PDF report complete with severity color bars, cryptographic hashes, metric scores, and remediation steps.
